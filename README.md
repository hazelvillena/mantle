# Mantle

A workspace for designing physical covers around existing engineering. The first demo is an exterior for one link of a robot arm.

This branch holds the scope. The app is not built yet.

## Read

- [Product](docs/product.md) — what we are building. Update this as the work changes.
- [Decisions](docs/decisions.md) — choices that would be costly to undo.
- [Roadmap](docs/roadmap.md) — now, next, and later.
- [Briefs](design/briefs.json) and [design language](design/language.json) — the starting vocabulary.

## Run

Nothing to install yet. Phase 0 is a generated cover, a browser view, and a STEP export.
