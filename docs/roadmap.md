# Roadmap

## Now

- [x] Concise living spec
- [ ] Phase 0 — one cover around a prepared Moveo link, on screen, exported as STEP. One known clash and one clear case. A Guided design proposal drives the same parameters.

## Next

- [ ] Phase 1 — the workspace: one recipe, brief attributes, direct controls, undo, layers, export. Label the assistant Guided design.
- [ ] Phase 2 — three alternatives that differ in shape, a before/after view, and Slimmer with the seam lock held.
- [ ] Phase 3 — pose checks, a finding you can open, a supported fix, then a new check. Export follows the current revision.

## Later

- [ ] Phase 4 — lighting, type, motion preferences, a timed run on this machine. A second part only if the first path is solid.
- [ ] Live model, behind the same design record, off by default.
- [ ] A second machine. Sketches and reference images. More export formats.

## Not in this POC

Arbitrary robots, a full-body exterior, generated CAD code, mechanical redesign, safety certification, accounts, billing.
